# The Green Buffet — till card

Print this and tape it by the till.

---

## Start of shift
1. Count the float
2. **Till → Open the till →** type the float

## Each order
1. Tap the items · choices open by themselves
2. **−** **+** for quantity · small box for *no onion*
3. Takeaway / Eat in / Delivery
4. **Phone number** → stamp card (9th bowl or burrito free, automatically)
5. **Promo code** if they have one
6. **Go to payment**

## Payment
| | |
| --- | --- |
| **Cash** | Type *Cash given* → check the change on screen |
| **Airtel / MTN / Zamtel / Card** | Take it on their machine → type the **transaction number** |
| **On account** | Manager's approval, and a name |

Part cash, part mobile money is fine — take one, the rest shows as owing.

**Print the receipt → Next order**

## End of shift
1. Count the whole drawer
2. **Till → Close the till →** type the total
3. Tell the manager about any difference

---

**Never share your password.** Every sale is recorded under whoever is signed in.

Stuck? Manager first. The system keeps everything already entered.
